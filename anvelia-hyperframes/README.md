# Anvelia HyperFrames

This folder contains the fixed-timeline HyperFrames adaptation of the Anvelia opening scroll show.

## Composition

- Composition ID: `anvelia-opening-show`
- Canvas: `1920x1080`
- Duration: `10s`
- Source: `index.html`
- Assets: `assets/`

## Timeline Labels

- `opening`: `0s`
- `mist-bridge`: `2.2s`
- `hero-reveal`: `4.8s`
- `clarity`: `6.8s`
- `title`: `7.8s`
- `hold`: `10s`

## Commands

Run these from this folder when the HyperFrames CLI is available:

```bash
npm run lint
npm run inspect
npm run preview
npm run render
```

Preview URL after `npm run preview`:

```text
http://localhost:3017/#project/anvelia-hyperframes
```
